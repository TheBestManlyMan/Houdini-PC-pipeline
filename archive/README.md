# Archive

These files are no longer part of the active pipeline. They are preserved here for reference only.

## publish_gallery.py
Legacy static HTML gallery generator. Scanned `publish_meta.json` files and emitted a self-contained HTML page.
Superseded by the React web gallery (`web/`) served by `api_server.py`. No current code imports or calls this.

## gallery_launch.py
Houdini shelf tool that launched `publish_gallery.py`. Archived together with its only dependency.
